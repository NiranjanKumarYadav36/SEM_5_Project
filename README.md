# Wild Insights - Wildlife Tracking Platform 🐾

![Wildlife Tracking](https://img.shields.io/badge/Wildlife-Tracking-brightgreen)
![Django REST](https://img.shields.io/badge/Django-REST%20API-blue)
![Google Maps](https://img.shields.io/badge/Google-Maps%20API-red)

A Django-based platform for real-time wildlife tracking and conservation analytics, awarded **3rd place** in INNOQUEST 2024.

## 📅 Project Duration
August 2024 - October 2024

## 🚀 Key Features
- **Real-time Animal Tracking**: Monitor wildlife movements via GPS collars
- **Interactive Maps**: Google Maps integration for location visualization
- **Performance Optimization**: 40% API payload reduction through query optimization
- **Conservation Analytics**: Habitat usage patterns and migration analysis

## 🛠️ Technologies Used
- **Backend**: Django REST Framework
- **Frontend**: React, Typescript, Material UI with Google Maps API
- **Database**: PostgreSQL (Spatial data support)

## 🏆 INNOQUEST 2024 Achievement
Secured **3rd place** among 45+ college teams for innovative wildlife monitoring solution.
